linkward

When another application hands a link to this browser, linkward asks where it should open before it opens — or copies it and opens nothing.

linkward is not watching anything yet. Switch it on below and allow the access Firefox asks for. Until then every link opens as it always did.

Another add-on is also deciding where links open.

    Firefox hands the same request to every add-on that asked to hold one, and none of them can see the others — there is no way to list another add-on's listeners. So when two of them both take a link and reopen it, Firefox does both: one click becomes two tabs, same address, same container. Neither add-on is broken, which is why this is easy to live with for weeks without working out what it is.

    Both add-ons are still holding the same requests, so a site neither of them has published a rule for can still open twice. Switch the master switch above off to leave every link to the other one.

    Switching this on asks for access to all websites. It is what lets linkward stop a page before it loads, so nothing is fetched and no session is started in the wrong container. Switching it off hands the access back.
